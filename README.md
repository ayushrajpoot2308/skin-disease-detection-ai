# Skin Disease Detection using Deep Learning

## Overview
This project is an AI-powered skin disease detection system that uses Deep Learning and Computer Vision techniques to classify skin diseases from uploaded images.

The goal of this project is to assist users in identifying possible skin diseases using image-based analysis.

---

## Features
- Upload skin disease images
- AI-based disease prediction
- CNN-powered image classification
- Simple and user-friendly web interface
- Real-time prediction results

---

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- Flask
- NumPy
- HTML/CSS/JavaScript

---

## Project Workflow

1. User uploads an image
2. Image preprocessing is performed
3. Deep Learning model analyzes the image
4. Disease category is predicted
5. Result is displayed to the user

---

## AI Implementation

This project uses Convolutional Neural Networks (CNNs) for image classification.

The model learns visual patterns such as:
- texture
- color variation
- lesion structure

Image preprocessing and normalization techniques were used to improve prediction quality and consistency.
